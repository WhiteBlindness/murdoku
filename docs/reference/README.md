## Conjunto histórico Sol

Este conjunto foi captado em 07/09/2026, numa compilação local do ramo
`sol/isometric-system-hardening`. As imagens de computador usam uma janela de
1 440 × 1 100 píxeis. As imagens móveis usam 390 × 844 píxeis, entrada tátil e
o mesmo motor de renderização.

O conjunto é deliberadamente pequeno. Cada imagem prova uma decisão de
arquitetura, interação ou adaptação responsiva; não é um arquivo de iterações.
Os pedidos externos de tipos de letra e retratos foram bloqueados durante a
captura. O navegador usou as alternativas locais previstas e não emitiu avisos
do validador de cenas.
